# cards-article

Custom **cards** block. Purpose: Related article cards at the end of an article.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: one row per article; cell 1 is the image (optionally linked to the article), cell 2 holds a category link paragraph followed by a title link paragraph.

## Supported variations

No variations.
