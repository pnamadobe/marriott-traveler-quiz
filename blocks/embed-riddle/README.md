# embed-riddle

Custom **embed** block. Purpose: Embeds a third-party Riddle.com quiz in the article column.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: one row, one cell holding a link to the Riddle embed URL (https://www.riddle.com/embed/a/<id>); link text, when not a URL, becomes the iframe title.

## Supported variations

No variations.

N/A (Document Authoring project)
